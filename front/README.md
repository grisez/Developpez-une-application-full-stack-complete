# MDD front-end

Angular 20 application. Setup, commands and conventions are described in the [main README](../README.md) and in [ARCHITECTURE.md](../ARCHITECTURE.md).

| Action | Command |
| --- | --- |
| Install the dependencies | `npm install` |
| Start the dev server on http://localhost:4200 | `npm start` |
| Build for production | `npm run build` |
| Run the unit tests (watch mode) | `npm test` |
| Run the unit tests once, headless | `npm run test:ci` |
